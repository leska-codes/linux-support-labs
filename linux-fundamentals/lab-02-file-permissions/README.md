# Лабораторная работа №2. Управление правами доступа в Linux 🔐

## Проект: ByteForge

### 1. Цель работы

Закрепить практические навыки управления правами доступа к файлам и каталогам в Linux.

В ходе лабораторной работы отрабатываются:

- изменение прав доступа с помощью `chmod`;
- изменение владельцев и групп с помощью `chown`;
- настройка специальных битов;
- работа с Sticky Bit;
- настройка маски создания файлов и каталогов с помощью `umask`;
- проверка результатов через терминал.

### 2. Легенда

В компании ByteForge готовятся к выпуску нового программного продукта. Команда разработки хранит техническую документацию на Linux-сервере.

Во время внутренней проверки выяснилось, что сотрудник отдела аналитики случайно получил возможность изменять технические файлы разработчиков. Кроме того, временная папка компании устроена неправильно: сотрудники могут удалять чужие файлы.

Задача — привести права доступа в порядок и обеспечить безопасную организацию рабочих каталогов.

- Операционная система: Ubuntu Linux
- Имя компьютера: Ubuntu

### 4. Выполненные задания

#### Часть 1. Защита технического отчёта

Создан файл:

`/home/olga/release_report.txt`

Назначены владелец и группа:

- Владелец: `olga`
- Группа: `support`
- Права доступа: `640`

Итоговые разрешения:

```text
-rw-r-----
```

Владелец может читать и изменять файл, группа — только читать. Остальные пользователи доступа не имеют.

#### Часть 2. Разделение рабочих каталогов

Создана структура каталогов:

```text
/opt/byteforge/
├── support/
├── analytics/
└── shared/
```

Настроены права доступа:

| Каталог     | Владелец | Группа    | Права |
| ----------- | -------- | --------- | ----- |
| `support`   | olga     | support   | 770   |
| `analytics` | marina   | analytics | 770   |
| `shared`    | root     | root      | 777   |

Для проверки использовалась команда `ls -ld`.

#### Часть 3. Общая временная папка

Создан каталог:

`/opt/byteforge/shared/tmp`

Установлен Sticky Bit с помощью команды:

```bash
chmod 1777 /opt/byteforge/shared/tmp
```

Результат проверки:

```text
drwxrwxrwt
```

Sticky Bit ограничивает удаление и переименование чужих файлов в общем каталоге. Удалять файлы могут их владельцы, владелец каталога и суперпользователь root.

#### Часть 4. Скрипт технической проверки

Создан файл:

`/home/olga/health_check.sh`

Всем категориям пользователей добавлено право на выполнение.

Использованная команда:

```bash
chmod a+x /home/olga/health_check.sh
```

Итоговые права:

```text
-rwxrwxrwx
```

Файл принадлежит пользователю `root`, поскольку был создан из-под административной учётной записи.

Примечание: разрешение на выполнение не означает, что файл автоматически содержит работающую программу. В этой части лабораторной проверялись именно права доступа.
